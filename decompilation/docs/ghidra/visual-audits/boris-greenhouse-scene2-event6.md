# Boris Greenhouse: Scene 2 event 6

## ROM route

Scene 2 record 87 is at `0x173110`. Its event code is 6, and the event table's
row 6 contains the byte for Scene 26. Indexed title service 10 at `0x53F8C`
matches Scene 2/event 6 first, loads dialogue profile `0x121F58`, calls the
shared runner at `0x1F246`, and returns D6=-1. The table's Scene-26 value is
therefore suppressed; closing the service returns to Scene 2.

The service dispatches on signed `FFF0D5`, byte `FFFC26`, and story/item flags.
The default path uses text roots at `0xF4C70` and `0xF4C84`. Command `0x25`
checks FFFC26 bit 3; command `0x26` selects the $100 story offer from bit 0;
command `0x27` charges the wallet and sets bit 0. Command `0x29` charges $500
and sets bit 2 before the gated topic list. Michael, David, and Ilene choices
also update the source FFFC1E/FFFC30/FFFC34 facts. The Brother? choice reaches
command `0x2C` at `0x21BE4`, whose Strike Team effect is not converted yet.
Commands `0x2D`–`0x2F` and their item-purchase return paths remain outside this
implementation.

## Implementation and evidence

`boris_greenhouse.lua` owns the same-map choices, payment decisions, and typed
story changes. The entity link keeps the source table destination as evidence
while priority 10 selects the Lua task. C++ presents the Lua dialogue and
persists FFFC26 at save payload offset `0x22C`. The text and profile portrait
are regenerated by the explicit ROM asset extractor.

The Debug/Release script suite checks the indexed route, payment outcomes, and
conditional topics. Debug and Release Qt QA walk ordinary Up into Scene-2
record 87, check the full portrait dialogue, buy the $100 story response,
return to Scene 2, and verify FFFC26 and nuyen across save restore. The full-screen
captures are in `build/conversion/qt/<config>/qt_runtime/field-boris-greenhouse-dialogue-qa/`.
The captures are internal runtime evidence; no independent Genesis dialogue
frame has been identified. Keep the service partial until the remaining ROM
branches and independent visual evidence are addressed.
