# Direct Shadowrun assets

Generated from the US Genesis ROM by shadowrun_graphics_extract --all-assets.

The native runtime consumes these individually named BMPs, `native/state.bin`, and the single `resources.tsv` alias manifest. This tree deliberately contains static intro plates and independently extracted intro sprites; it does not contain full-screen flipbook samples or an aggregate serializer.

Genesis audio is not emitted here until its Z80 event format is decoded into complete usable files. Raw ROM slices and split event fragments are analysis inputs, not runtime assets.
